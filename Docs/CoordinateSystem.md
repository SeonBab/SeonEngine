# 좌표계와 단위

## 길이 단위

엔진의 월드 공간에서 길이 1 unit은 1cm입니다. 따라서 100 units는 1m입니다.

위치와 이동 거리에는 이 기준을 적용합니다. 초 단위 시간으로 계산하는 이동 속도의 단위는 cm/s입니다.

Vector3 자체는 단위를 강제하지 않으며, 사용하는 값의 의미에 따라 단위가 정해집니다. 예를 들어 크기(scale)는 단위가 없는 축별 배율이며 1이 원래 크기입니다.

## 축 방향

엔진의 3차원 공간은 왼손 좌표계를 사용합니다. 기본 축 방향은 다음과 같습니다.

| 축 | 양의 방향 |
|---|---|
| +X | 오른쪽 |
| +Y | 위쪽 |
| +Z | 앞쪽 |

이는 Direct3D의 왼손 좌표계 설명과 같은 축 배치입니다. 여기서 앞쪽은 기본 좌표축의 방향이며, 회전한 객체나 카메라의 전방이 항상 월드 +Z라는 뜻은 아닙니다.

## 회전

회전을 입력하고 읽을 때는 도 단위 오일러 각인 `EulerAngles`를 사용합니다. 각 값의 회전축과 양의 방향은 다음과 같습니다.

| 값 | 회전축 | 양수일 때 |
|---|---|---|
| pitch | X축 | 앞쪽(+Z)이 아래쪽(-Y)으로 숙여짐 |
| yaw | Y축 | 앞쪽(+Z)이 오른쪽(+X)으로 돌아감 |
| roll | Z축 | 위쪽(+Y)이 왼쪽(-X)으로 기울어짐 |

세 회전은 roll(Z축), pitch(X축), yaw(Y축) 순서로 적용합니다. 이는 DirectXMath `XMMatrixRotationRollPitchYaw`의 정의와 같습니다.

엔진 내부에서는 회전을 `Quaternion`으로 저장하고 계산합니다. 오일러 각은 입력할 때 쿼터니언으로 바뀌므로, 다시 읽으면 같은 회전을 나타내는 다른 각도가 나올 수 있습니다. 읽은 값의 범위는 pitch -90~90, yaw와 roll -180~180입니다. 예를 들어 yaw 190을 넣으면 -170으로 읽힙니다. pitch가 90도나 -90도에 가까우면 yaw와 roll을 구분할 수 없으므로 roll을 0으로 두고 나머지를 yaw로 나타냅니다.

## 행렬

변환 행렬은 `Matrix4x4`로 표현하며 `m[행][열]`로 접근합니다. 행 벡터 규칙을 사용하므로 점이나 방향은 행렬의 왼쪽에 두고 `v * M`으로 변환합니다.

이동 성분은 마지막 행의 `m[3][0]`, `m[3][1]`, `m[3][2]`에 있습니다. 여러 변환은 적용할 순서대로 왼쪽부터 곱합니다. 예를 들어 크기, 회전, 이동 순서로 적용하는 행렬은 `크기 * 회전 * 이동`입니다.

이는 DirectXMath의 행렬 규칙과 같습니다. 셰이더로 보낼 때 전치가 필요한지는 렌더러가 정합니다.
