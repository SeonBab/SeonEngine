# 개발 문서

저장소를 받아 빌드하고 개발하거나 다른 렌더러를 연결할 때 사용하는 안내다. 현재 함수 계약의 세부 조건은 각 소스 헤더의 주석을 함께 따른다.

| 문서 | 내용 |
|---|---|
| [BuildSetup](BuildSetup.md) | 개발 환경, 프로젝트 생성과 빌드, 의존성, 실행 구성과 출력 경로 |
| [RendererIntegration](RendererIntegration.md) | 다른 렌더러의 어댑터 구현, 공통 데이터와 수명, 생성 함수, 빌드 연결과 검증 절차 |
| [CodeConvention](Conventions/CodeConvention.md) | 코드 작성과 주석, 파일 구성, 소유와 실패 처리 규칙 |
| [GitConvention](Conventions/GitConvention.md) | 브랜치, 커밋과 Git 작업 규칙 |
